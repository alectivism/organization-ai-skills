# Start here

This folder is your vault. It is a normal folder on your Mac, and these are normal text
files. If you delete Obsidian tomorrow, every note in here still opens.

Nobody else can see this. It is not synced to the org and there is no admin view.

## The three things worth knowing

**Search:** `Cmd-Shift-F` searches every note at once, including the words inside them.
This is the one you will use every day.

**Jump to a note:** `Cmd-O`, then type part of its name. You never have to remember which
folder something is in.

**Link two notes:** type `[[` and pick a note. Then open that other note and look at the
bottom of the screen: your link is listed there too. Links work in both directions, which
is the thing folders cannot do.

That is genuinely all you need. Plugins, tags, templates and the graph view can wait
months, or forever.

## Do not judge this in week two

Linking starts being useful somewhere around a hundred notes. Before that it feels like
pointless admin, and that is the normal experience rather than a sign it is not working.
Most people who give up give up here.

So do not organize anything yet. Write notes, use search, and let structure appear when
not having it starts to annoy you.

## Claude can read this folder

If you point Claude Cowork (or an equivalent AI agent that reads local files) at this
same folder, it can read everything in here. There is no connector to set up and no
integration to configure: both programs are just reading files off your disk.

That works in both directions. Ask Claude to write a summary into this folder and it
shows up in Obsidian.

## What to do next

Write one note about anything. A call you had, a decision you made, something you looked
up twice this week, and then close this file.
