# Personal voice profile template

Use this when the user wants their voice captured for reuse. If a personal writing skill, profile, or style file already exists, add to that one instead of starting a parallel profile.

## Quick version (five questions)

Most people need only this. Ask once, fill it in, and stop.

1. Paste two or three messages you have actually sent that sound like you.
2. How do you open and sign off, word for word?
3. Anything you never want in your writing (a word, a greeting, emoji, exclamation points)?
4. Where does your tone change: leadership, close colleagues, external partners?
5. Anything a stand-in would get wrong about how you write?

Turn the answers into the Confirmed preferences section below, and offer to save it as a personal skill (`~/.claude/skills/<name>-writing-style/SKILL.md` in Claude Code) or in their user instructions file.
